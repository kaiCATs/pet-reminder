## 🐶 О проекте

**Pet Reminder** — это desktop-приложение с анимированным питомцем,
который живёт на рабочем столе и напоминает о важных датах.

Приложение работает в системном трее и сохраняет данные локально в `%APPDATA%`.

---

## ✨ Возможности

### 🐾 Анимированный питомец

- Idle, Click, Sleep анимации
- Перетаскивание по экрану
- Не выходит за границы рабочего стола
- Зеркалирование спрайта: левая половина экрана — смотрит влево, правая — вправо
- Запоминает позицию между запусками
- Поверх всех окон, работает через системный трей

### 💬 Чат-помощник

- Добавление событий и дней рождения через естественный язык
- Диалог с кнопками-подсказками: повтор, время, пол, период напоминания
- Понимание сокращений, числовых и буквенных форм времени суток
- Редактирование событий через чат: дата, время, название, повтор
- Удаление событий и ДР через чат с нечётким поиском по названию
- Определение пола по имени; переспрашивает при двуполых именах (Саша, Женя)
- Правильное склонение имён в дательный и родительный падежи

### 🎂 Дни рождения

- Добавление и удаление через чат или GUI
- Настраиваемое напоминание: время + за сколько до даты + повтор
- Автоматический подсчёт возраста и правильное склонение (год / года / лет)
- Понимание возраста на входе: «28», «28 лет», «1990» — все варианты
- Защита от повторных уведомлений в течение дня

### 🗓 События

- Название, дата и время; настраиваемое напоминание (в момент / за N мин / за день)
- Повторяющиеся события: каждый день / неделю / месяц / год
- Редактирование двойным кликом в GUI или командой «измени» в чате
- Удаление через ПКМ в GUI или командой «удали» в чате
- Показ ближайших событий с датой (без «через N дней»)

### 🔔 Уведомления

- Toast-окна в правом нижнем углу с плавной анимацией
- Раздельный стиль для ДР (тёмный) и событий (синий)
- Автоматическое закрытие через 6 секунд

### 🌙 Темы оформления

- Переключение тёмной/светлой темы в окне событий (кнопка 🌙/☀️)
- Сам виджет календаря сохраняет светлую палитру (без артефактов отрисовки)
- Выбор темы сохраняется между запусками

### ⚙️ Прочее

- Автозапуск с Windows через реестр (включается из трей-меню)
- Все данные хранятся локально в `%APPDATA%\PetReminder`

## 💾 Хранение данных

Данные сохраняются в:

```
%APPDATA%/PetReminder
```

Файлы:

- `events.json` — список событий и дней рождения
- `birthday_notified.json` — кеш уведомлений о ДР
- `events_notified.json` — кеш уведомлений о событиях
- `position.json` — последняя позиция питомца на экране
- `chat_settings.json` — настройки чата (шрифт, размер окна, тема)

## 🚀 Запуск из исходников

Проект запускается напрямую из файла `pet.py`.

### 📁 Структура проекта

```
pet-reminder/
│
├── pet.py
├── assistant.py
├── chat_window.py
├── birthday_manager.py
├── calendar_widget.py
├── event_window.py
├── events_manager.py
├── tutorial.py
├── config.py
├── icon.ico
├── Icon.png
├── version.txt
│
├── idle_clean/
├── click_clean/
└── sleeping_clean/
```

⚠️ Файлы `icon.ico` и `Icon.png` должны лежать рядом с `pet.py`.

---

### 1️⃣ Склонируйте репозиторий

```
git clone https://github.com/kaiCATs/pet-reminder.git
cd pet-reminder
```

### 2️⃣ Проверьте Python (3.10+)

```
python --version
```

Если Python не установлен — скачайте с https://www.python.org/

### 3️⃣ Установите зависимость

```
pip install PyQt5
```

Если `pip` не срабатывает:

```
python -m pip install PyQt5
```

### 4️⃣ Запустите приложение

```
python pet.py
```

---

## ❗ Важно

- Запускать нужно **из корневой папки**, где лежит `pet.py`
- Все модули должны лежать рядом с `pet.py`
- Папки `idle_clean`, `click_clean`, `sleeping_clean` должны быть в той же директории
- Автозапуск корректно работает только в собранном `.exe`

---

## 📦 Сборка в exe

```
pyinstaller --noconfirm --clean --onefile --windowed ^
--icon=icon.ico ^
--version-file=version.txt ^
--add-data "idle_clean;idle_clean" ^
--add-data "click_clean;click_clean" ^
--add-data "sleeping_clean;sleeping_clean" ^
--add-data "Icon.png;." ^
pet.py
```

Или через готовый spec-файл (рекомендуется — включает оптимизации и скрытые импорты):

```
pyinstaller pet.spec --clean --noconfirm
```

## 📝 Changelog

### v10.2 — текущая версия

**Чат-помощник — новые возможности**

- Добавлен полноценный диалоговый поток для добавления событий: название → дата → время → повтор → за сколько напомнить. Каждый шаг сопровождается кликабельными кнопками-подсказками.
- Аналогичный пошаговый диалог для дней рождения: имя → (пол при двуполом имени) → дата → возраст → время → за сколько напомнить → повтор.
- Добавлено редактирование событий через чат: «исправь», «измени», «перенеси», «переименуй». Поддерживается одной фразой («перенеси встречу на 30 мая») или пошагово с кнопками «Дата / Время / Название / Повтор».
- Добавлено удаление через чат с нечётким поиском по стему слова — «удали встречу» находит «Встреча», «удали др ани» находит «День рождения Ани».

**Чат-помощник — исправления и улучшения**

- Исправлен парсинг времени: теперь понимает «в час дня» (13:00), «в три ночи» (3:00), «13 45», «15 00», «6 дня», «9 утра», «три часа вечера» и все падежные формы числительных.
- Убрано разворачивание сокращения «с» → «сегодня» — оно ломало любые фразы с предлогом «с» («встреча с врачом» → «встреча сегодня врачом»). Аналогично убрано «ч» → «часов», которое ломало «в час дня».
- Исправлен баг с годом при добавлении ДР: «28» из фразы «др Тани 28 мая» больше не интерпретируется как год рождения 2028, что давало возраст −2.
- Помощник правильно обрабатывает смену намерения в середине диалога: если во время ожидания имени пользователь пишет фразу с датой — предыдущий контекст сбрасывается.
- Добавлено слово «др» в распознавание только в начале фразы; в середине («покажи какие др и события есть») оно теперь не запускает добавление ДР.
- «покажи» и его вариации теперь корректно показывают события и ДР без падения. Разделены списки событий и дней рождения.
- Вывод ближайших событий: показывается дата («28 мая»), а не «через 19 дней».

**Дни рождения**

- Настраиваемое время напоминания (раньше было жёстко 00:00 и за 1 день).
- Диалог добавления теперь спрашивает: время уведомления, за сколько до даты напомнить, повтор.
- Понимает возраст на входе: «28», «28 лет», «1990» — все три варианта приводят к году рождения.
- Добавлено определение пола по имени с автосклонением в дательный и родительный падеж. При двуполых именах (Саша, Женя, Валя, Коля и др.) переспрашивает кнопками 👨 Мужское / 👩 Женское.
- Правильное склонение числительных: 1 год, 2 года, 5 лет, 21 год, 22 года.
- Исправлено удаление ДР через чат: «удали др ани», «удали день рождения ани» — работает с нечётким поиском.

**События**

- Настраиваемое напоминание с кнопками: В момент / За 15 мин / За 30 мин / За час / За день.
- Добавлено признание события без слова «добавь»: «зубной завтра в 14» запускает диалог добавления.
- Подтверждение создания события показывает выбранное время и период напоминания.
- Исправлено извлечение названия события: «добавь встречу» больше не теряет «встречу» из-за фильтрации ключевых слов.

**Окно событий — тёмная тема**

- Добавлена кнопка 🌙/☀️ в шапке окна событий для переключения темы.
- Тёмная тема применяется к фону, списку событий, заголовкам, кнопкам.
- Сам виджет `QCalendarWidget` намеренно остаётся светлым — перекраска его внутренней таблицы вызывала визуальные артефакты.
- Выбор темы сохраняется в `chat_settings.json`.

**Кнопки-подсказки в чате**

- Кнопки теперь переносятся на следующую строку если не помещаются в ширину окна (раньше выстраивались в одну линию и съедали место).
- Ширина пузырей сообщений стала динамической (75% ширины окна вместо фиксированных 300px) — исчезло обрезание текста при узком окне.
- Минимальная ширина окна чата увеличена с 320 до 380px.

**Интерфейс**

- Удалена кнопка «Настройка помощника» из шапки чата.
- Добавлена кнопка «Отмена» / команды «стоп», «отмена», «забудь» для выхода из любого диалога.
